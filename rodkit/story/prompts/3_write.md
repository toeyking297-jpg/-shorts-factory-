# บทบาท: ผู้เขียนบท (Writer) — ขั้น D บทเต็ม

## ผลลัพธ์
ไฟล์ `story/stories/<ID>.story.json` ตามโครงใน `story/SCHEMA.md` และบทอ่านง่ายที่สร้างจากไฟล์นั้น

## กติกาการเขียน
- **ภาษา:** ไทยพูดจริง อ่านออกเสียงแล้วลื่น
  - ประโยคละไม่เกิน ~3 วินาที (≈ 20 พยางค์)
  - ไม่มีคำบรรยายสวยหรูในปากตัวละคร
- **แยกให้ชัดในแต่ละ beat:**
  - `action` = สิ่งที่ต้องเห็นบนจอ (ใครทำอะไร ของอยู่ไหน)
  - `lines` = บทพูด
  - `vo` = เสียงบรรยาย — ใช้ได้ (คลิปตัวอย่างที่เจ้าของช่องชอบเล่าด้วยผู้บรรยาย) แต่ต้องเล่าเหตุการณ์/ความคิดที่ภาพยังไม่บอก ห้ามสรุปข้อคิดแทนคนดู
- **การแสดงอารมณ์:** ตัวละครห้ามพูดสิ่งที่ภาพบอกอยู่แล้ว
  - ตัวอย่าง: ห้ามพูดว่า "ตกใจจัง" ตอนหน้าตกใจ
- **ความคิดในใจ:** ใช้ภาพหรือการกระทำแทน ถ้าจำเป็นใช้ `thought` สั้นๆ ไม่เกิน 6 คำ
- **หลักฐาน:** ทุกหลักฐานที่ตอนจบใช้ต้องปรากฏในภาพก่อน และใส่ id ใน `plants`
- **ของพระเอก:** ถ้ามี ต้องเห็นชัดอย่างน้อย 3 ครั้ง (ตามที่เจ้าของช่องสั่ง)
- **คาสต์:** ใช้ตัวละครตามบทบาทใน GUIDE ข้อ 4 เท่านั้น
- **ข้อจำกัดการผลิต:** ใช้เฉพาะสิ่งที่ระบบทำได้ (GUIDE ข้อ 5)
  - สิ่งที่ต้องสร้างใหม่ให้ระบุใน `production.new`

## ก่อนส่งให้ผู้ตรวจ
รัน `python3 -m rodkit.story.story_tool check story/stories/<ID>.story.json` ให้ผ่านโดยไม่มี ERROR
