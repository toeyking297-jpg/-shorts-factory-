ใช้กับช่องดูเพลินเท่านั้น ห้ามนำข้อกำหนดของช่องอื่นมาใช้ (เช่น กฎรอดตาย, Shorts Factory อังกฤษ, โลกซ่อนเรื่อง)
ทุกบรรทัดติดป้าย: [ยืนยัน] = เจ้าของช่องพูด/สั่งไว้ · [สมมติฐาน] = ใช้ทดลอง รอผลจริง · [ไม่ทราบ] = ยังไม่มีข้อมูล

## 0. แนวเรื่องประจำช่อง [ยืนยัน 2026-11-20]
**"เรื่องเล่าสะท้อนชีวิตแบบเปลี่ยนมุมมอง"**
- เรื่องใกล้ตัวสำหรับผู้ใหญ่ ความขัดแย้งเข้าใจง่าย แต่มีเหตุผล/บริบทอีกด้านที่คนหรือตัวละครมองข้าม
- การกระทำและผลลัพธ์ทำให้มุมมองเปลี่ยน จนภาพ/เหตุการณ์/คำพูดตอนต้นมีความหมายใหม่ตอนท้าย
- อารมณ์เป้าหมาย: "ตอนแรกคิดอีกอย่าง พอรู้ทั้งหมดแล้วเข้าใจอีกอย่าง" + สะเทือนใจ / อบอุ่น / เสียดาย / รู้สึกถูกเข้าใจ (เลือกตามเรื่อง ไม่บังคับเศร้าหรือจบสุข)
- ความเข้มข้นมาจาก:
  - ความต้องการชัด
  - การตัดสินใจที่มีต้นทุน
  - ความขัดแย้งที่กระทบใจ
  - ผลของการกระทำ
  - ความจริงที่เปลี่ยนความเข้าใจ
- ห้ามเร่งความเข้มด้วย:
  - การตะโกน
  - คนร้าย
  - อุบัติเหตุ
  - ความตาย
  - คำบรรยายเศร้าที่ไม่มีเหตุผลรองรับ
- ห้ามเฉลยด้วยสมุดลับ/จดหมาย/กล้องวงจรปิดซ้ำๆ
  - ตัวตรวจจะจับถ้าวิธีเฉลยซ้ำกับ 3 เรื่องล่าสุด
- การเปลี่ยนมุมมองอาจเกิดกับตัวละคร หรือกับคนดูอย่างเดียวก็ได้
  - ไม่บังคับให้ทุกตอนมีคนเข้าใจผิดแล้วสำนึกผิด
- หมุนหัวข้อ:
  - ครอบครัว
  - การทำงาน
  - มิตรภาพ
  - ความไว้ใจ
  - ความคาดหวัง
  - ความรับผิดชอบ
  - การตั้งขอบเขต
  - คุณค่าที่ถูกมองข้าม
- คำสั่ง "สร้างคลิปความยาว N นาที" = ทำเองทั้งหมดจนได้ไฟล์
  - ห้ามส่งพล็อตให้เลือก
  - ห้ามขออนุมัติบท
  - ไม่เผยแพร่ เว้นแต่สั่ง
  - ดูขั้นตอนที่ `prompts/0_autopilot.md`

| ช่วง (วิ) | หน้าที่ |
| --- | --- |

| 8–25 | ตัวละคร ความต้องการ ความขัดแย้ง (เฉพาะที่จำเป็น) |

- หนึ่งประเด็น
- ไม่เล่าความรู้สึกซ้ำ
- ไม่บรรยายสิ่งที่ภาพบอกแล้ว
- ไม่ย้อนเหตุการณ์ทั้งชุดเพื่ออธิบายเฉลย
- ตัดคำสอนใจกลางๆ
- เว้นจังหวะให้ภาพ ปฏิกิริยา และความเงียบทำงาน

## 2.1 คลิปตัวอย่างที่เจ้าของช่องบอกว่า "เนื้อหาดี" (ส่งมา 2026-11-20)

  - [สมมติฐาน] เจ้าของช่องให้น้ำหนักเรื่องมากกว่าความละเอียดของภาพในเรื่องนี้

## 6. หลักเล่า (สรุป — รายละเอียดใน prompts/)
- ทุกเรื่องต้องตอบ 7 ข้อ:
  1. ติดตามใคร
  2. ต้องการอะไร
  3. อะไรขวาง
  4. ถ้าพลาดจะเสียอะไร
  5. เขาตัดสินใจอะไร
  6. ผลของการตัดสินใจ
  7. ตอนจบเปลี่ยนอะไร
- เปิดด้วยเหตุการณ์/ความผิดปกติที่เห็นเป็นภาพภายใน 3 วินาที
  - ไม่เปิดด้วยผู้บรรยายเล่าเวลา/ประวัติ
- จังหวะเรื่องเชื่อมด้วย "เพราะ…จึง" หรือ "แต่…กลับ"
  - ถ้ามี "แล้วก็" ติดกัน 2 ช่วง ให้รื้อโครง
- ตัวเอกต้องเป็นคนตัดสินใจที่พลิกเรื่อง ไม่ใช่ให้คนอื่นหรือโชคทำแทน
- อารมณ์มาจากการกระทำ/การเลือก/การเสีย ไม่ใช่ผู้บรรยายบอก
- หมุนกลไกข้อมูลคนดู:
  - รู้น้อยกว่า
  - รู้มากกว่า
  - รู้ปัญหาแต่ไม่รู้ทางแก้
